## Быстрый старт для Windows

1. Перейдите на страницу [релизов](https://github.com/SaBog/litres-pdf/releases) и скачайте последнюю версию программы для Windows (zip с `litres-pdf.exe`, папкой `fonts` и `config.ini`).
2. Распакуйте архив и запустите `litres-pdf.exe` из этой папки: шрифты и настройки программа ищет рядом с собой.

## Установка и запуск из исходников

Нужен [uv](https://docs.astral.sh/uv/).

1. Клонируйте репозиторий
2. Установите зависимости: `uv sync`
3. Запустите приложение: `uv run python main.py`

## Как пользоваться

- При первом запуске откроется окно браузера (скачивается драйвер Chrome). Войдите в свой аккаунт LitRes. После этого программа запомнит ваш вход (файл `cookies.json`);
- Введите ссылку на книгу, которую хотите скачать, и следуйте подсказкам;
- Для выхода просто закройте программу или нажмите Enter без ввода ссылки;
- Вы можете изменить параметры работы приложения в файле `config.ini`.

### Какие ссылки понимает программа

| Ссылка | Пример |
|--------|--------|
| Страница книги (текст или PDF) | `https://www.litres.ru/book/автор/название-12345/` |
| Страница аудиокниги | `https://www.litres.ru/audiobook/автор/название-12345/` |
| PDF-читалка | `https://www.litres.ru/static/reader/pdf/index.html?file=…&art=…` |
| Текстовая читалка | `https://www.litres.ru/static/reader/text/index.html?art=…` |
| Старые читалки | `https://www.litres.ru/static/or3/view/or.html?file=…`, `…/or4/view/or.html?baseurl=…` |

Ссылки на ознакомительный фрагмент (`trials=1`) не поддерживаются: нужна книга из вашей подписки.

### Что скачивается

- Части книги попадают в `books-source/<название>/`, готовый файл в `books/`. Формат результата выбирается по приоритету из `OUT_FORMAT_PRIORITY` в `config.ini`;
- Дополнительные файлы книги (бонусный PDF, архив с материалами) сохраняются рядом с готовой книгой: `books/<название> - <имя файла>`;
- У книг с пометкой «pdf + epub» в названии рядом с PDF появится файл `… - <имя>.zip`: это архив, внутри которого лежит **epub** книги. Распакуйте его, чтобы получить `.epub`;
- Уже скачанные части и файлы повторно не скачиваются.

## Поддерживаемые форматы

| Книга | PDF | FB2 | TXT | MP3 |
|-------|:---:|:---:|:---:|:---:|
| Текстовая | 🟢 | 🟡 | 🟡 | 🔴 |
| PDF (сканы страниц) | 🟢 | 🔴 | 🔴 | 🔴 |
| Аудиокнига | 🔴 | 🔴 | 🔴 | 🟢 |

- 🟢 — поддерживается
- 🔴 — не поддерживается
- 🟡 — есть в программе, но не проверялось на новых читалках
- ⏳ — планируется
